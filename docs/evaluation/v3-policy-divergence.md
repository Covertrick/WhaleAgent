# 策略是否分开

开发集上五种策略的成功数不是同一条线：ReAct 20/24，EGAA 和整图重规划都是 10/24，只在缺证据时观察是 9/24，Always Refresh 是 7/24。

分开的地方主要不在计划 token。EGAA、Always Refresh 和 plan_only 的提示 token 都是 7886，因为计划提示相同、温度是 0。整图重规划把计划调用从 24 提到 36，成功数没有增加。

测试集上计划策略和 ReAct 仍然分开。ReAct 80/96，EGAA 58/96，Always Refresh 42/96。两种计划策略的提示 token 都是 31200，各 96 次计划调用。差别落在执行：Always Refresh 有 14 次过期写入，EGAA 有 4 次。两边都有 14 次“该有提醒却没有”。缺提醒是计划没写出提醒节点，或写入没有发生，不是刷新策略单独造成的。

EGAA 的 `value_from` 只能指向一份事实。目标要求一段草稿同时留下两份原文，或待办草稿不能混入新名字时，整份原文拷进去就会失败。ReAct 可以自己组织正文。这个差别算执行器限制，评分没有放宽。
