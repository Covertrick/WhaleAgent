# v3 统计

单位是蓝图。每个蓝图有两个变体、两次重复。Bootstrap 抽的是蓝图，不是单次轨迹。5000 次，种子 20261110。区间是 2.5% 到 97.5%。

差是左边减去右边。正数表示左边更高。

## 测试集，24 个蓝图

EGAA 减 Always Refresh：

| 量 | 均值 | 下界 | 上界 | 是否含 0 |
| --- | ---: | ---: | ---: | --- |
| 成功率 | 0.166 | 0.042 | 0.313 | 不含 |
| 观察次数 | 0.500 | 0.292 | 0.708 | 不含 |
| 单次 token | 1.30 | -0.42 | 4.04 | 含 |
| 每次成功 token | -344.3 | -931.9 | -54.4 | 不含 |

单次 token 是每条轨迹的提示加补全，先在蓝图内平均，再求差。每次成功 token 是一次重抽样里的总 token 除以成功次数，再求两边的差。5000 次里面没有出现成功数为 0 的抽法。每次成功 token 更低，是因为成功数不同，而两边的提示 token 总量都是 31200。

EGAA 减 ReAct：

| 量 | 均值 | 下界 | 上界 | 是否含 0 |
| --- | ---: | ---: | ---: | --- |
| 成功率 | -0.230 | -0.417 | -0.052 | 不含 |
| 观察次数 | -0.241 | -0.563 | 0.021 | 含 |
| 单次 token | -3795.6 | -4274.6 | -3302.2 | 不含 |
| 每次成功 token | -4342.8 | -5439.8 | -3528.9 | 不含 |

成功率上界 -0.052 低于 -0.05。按事先说的 5 个百分点界限，这份样本不支持 EGAA 相对 ReAct 的非劣。

## 开发集，只作描述

12 个蓝图。EGAA 减 Always Refresh 的成功率区间 [0, 0.333] 含 0。观察区间 [0.25, 0.75] 不含 0，EGAA 更多。EGAA 减 ReAct 的成功率区间 [-0.708, -0.125] 不含 0。开发集不参与选择，也不代替测试集。
