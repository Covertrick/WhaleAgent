# EGAA V1 归档结果

数字来自 `evals/statebench/d14_report.md`，不是这次重构重算的。人工任务语义复核在该文件和 `audit.md`、`frozen_config.json` 里都是 PENDING。比较对象是脚本化 ReAct 循环。模型费用不适用。

该文件的原话：在该冻结测试集和该脚本化配置下，证据门控策略的任务成功率高于脚本化 ReAct 循环，区间不含 0。这仍是受控环境里的规则比较。蓝图样本 20，任务样本 40，成功率差 0.5000，区间 [0.3000, 0.7000]。

冻结规则：`before_irreversible`，观察预算 3，重规划预算 2。文件同时写明 `evidence_age=10` 在验证集的决策时域内没有出现 age≥10，不能把未触发解释成风险控制发挥了作用。证据门控策略和每次写前刷新的任务成功率与工具调用数相同，不能把选择性观察写成更省调用。
