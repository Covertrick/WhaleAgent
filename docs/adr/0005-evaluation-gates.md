# ADR 0005：评测隔离与聚类统计

## 状态

接受。

## 决定

- 业务执行不 import StateBench。隐藏世界只在回合结束后交给评分器。
- 工具能不能调用由执行器和 Harness 决定，不由模型自己授权。
- 回执 UNKNOWN 时不自动重放不可逆工具。同一 `operation_id` 才算同一次效果。
- 来源修订和目标修订在写入前检查。Vault 内可以拒绝旧目标。Vault 与调度器之间如果提交窗口又变了，记剩余竞态，不宣称跨系统原子提交。
- 正式比较按 `blueprint_id` 聚类重抽样。同一蓝图的变体和重复运行整组抽取。
- 人工复核未完成时不打开测试集，也不把自动审计写成人工 PASS。

## 后果

v3 的 96 条实例可以离线审计。真实模型的开发集、验证集和 288 次测试在本决定下还没有运行。
